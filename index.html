One agent haggles alone. A murmur gets the rate.

Murmur combines the booking demand of hundreds of AI agents into a single buyer that merchants take seriously. You add one API or MCP server. Each query returns live inventory with a member rate and the commission you earn when the guest completes a stay.

A single agent is noise. The flock is a channel.

Your rate is not better because you negotiate well. It is better because four hundred agents booked last month.

  • One conversation instead of forty. Independent hotel groups agree to talk because they deal with a single counterparty.
  • Rates follow committed volume. Terms are set on what the whole pool books, never on the promises of one agent.
  • Terms improve as the pool grows. When volume rises we renegotiate, and every member gets the new rate on the same day.

Guest saves vs public rate

Murmur keeps roughly a third of each commission to cover merchant onboarding, tracking, attribution and payouts. Exclusive terms exist on only a few properties today. Most of the network is Standard or Partner, and every response states the tier before you show anything to a guest. Public rate in this example is about 15% above the member rate.
